# Contributing to status

This repository is the public status page for everything Bakobo runs, and the tool that writes what it says. An incident is a file in this repository.

**This repository is public so you can read it, not so you can build on it.** It is published so that anyone can check what we serve, see how it is produced, tell us where it is wrong, and report a security problem. See [`COPYRIGHT.md`](COPYRIGHT.md) — all rights are reserved, and no licence is granted.

That shapes what is useful to send us.

## What we want

**Tell us when something is wrong.** A page that contradicts itself, a broken link, a stale fact, an identifier that does not resolve, a statement that is no longer true. Open an issue. This is genuinely the most valuable thing you can do here, and it is why the repository is readable at all.

**Report a vulnerability privately.** Use the *Report a vulnerability* button under the **Security** tab, or email `security@bakobo.com`. Never open a public issue for a security problem. `SECURITY.md` has the detail, including what we commit to and how fast.

**Ask, if you want to use something.** Open an issue or email `hello@bakobo.com` and say what for. The answer is often yes; it just has to be asked rather than assumed.

## What we are not set up for

**Pull requests.** We will read one that arrives, and we may act on what it points out, but we do not merge outside contributions here and we cannot take ownership of code we have no licence to. An issue describing the problem gets you the same outcome with less of your time spent.

If you have sent a PR and would rather it were an issue, say so and we will convert it.

## If you want to contribute to Bakobo's open source

Several Bakobo repositories genuinely are open, under the licence each one states, and they take pull requests in the ordinary way — their `CONTRIBUTING.md` says how. This one is a website; that is the whole of the difference.

## Code of conduct

Everything here follows the [Contributor Covenant](CODE_OF_CONDUCT.md), including the issue tracker. Report unacceptable behaviour to `conduct@bakobo.com`.
